# Smartbin System Architecture & Ecosystem Presentation

Slide thuyết trình tương tác giới thiệu hệ sinh thái Smartbin (Quản lý thu gom rác thông minh, IoT Telemetry, AI tối ưu định tuyến, Microservices Architecture).

## Nội dung Slide
1. **Slide 1:** Đặt vấn đề & Thách thức quản lý rác thải đô thị
2. **Slide 2:** Tổng quan Hệ sinh thái Smartbin (8 Microservices)
3. **Slide 3:** Dịch vụ Thu gom Rác cồng kềnh (Bulky Waste Service)
4. **Slide 4:** Giám sát đoàn xe & Thiết bị IoT Traccar thời gian thực
5. **Slide 5:** Điều phối thông minh & Thuật toán tối ưu lộ trình
6. **Slide 6:** Kiến trúc Hệ thống Microservices & Luồng tích hợp IoT
